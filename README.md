# Naanprophet Javabrew

## How do I install these formulae?

`brew install naanprophet/javabrew/<formula>`

Or `brew tap naanprophet/javabrew` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "naanprophet/javabrew"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
